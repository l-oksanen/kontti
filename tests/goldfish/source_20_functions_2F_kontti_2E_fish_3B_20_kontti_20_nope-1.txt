Build and install the container of kontti, and run its launcher

USAGE
    kontti build
        Build the image from kontti.def, where the launcher here looks
        for it
    kontti install HOST
        Install the launcher as ~/bin/kontti on HOST (over ssh), with
        ~/images/kontti.sif as its default image, and the image where
        the launcher there looks for it; also the git identity of
        Claude and the terminfo entry of $TERM, if missing there
    kontti claude | shell | exec | config ...
        Run the launcher here

The launcher (kontti.sh, POSIX sh):

Run Claude Code in a container that sees only its own home directory

USAGE
    kontti claude [ARG...]
        Claude Code, installed into the home first if missing
    kontti shell
        bash
    kontti exec COMMAND [ARG...]
        COMMAND
    kontti config [home | image]
        Print the settings (home and image), or one of them

The container's home is a directory of the host (default ~/claude),
mounted at the same path; nothing else of the host is visible, nor its
environment, but TERM, COLORTERM, the proxy settings, LEAN_NUM_THREADS
and the job's SLURM_JOB_ID, SLURM_CPUS_PER_TASK, SLURM_MEM_PER_NODE and
SLURM_JOB_END_TIME. The working directory is the current one if it is in the
home, the home otherwise. /tmp is ${TMPDIR:-/tmp}/kontti-$USER of the
host, shared by the containers of the user.

Settings, in ${XDG_CONFIG_HOME:-~/.config}/kontti/config, lines NAME=VALUE
(a leading ~/ is the home of the host):
    home=~/claude
    image=${XDG_DATA_HOME:-~/.local/share}/kontti/kontti.sif
`kontti install` makes ~/images/kontti.sif the default image on the
host.
